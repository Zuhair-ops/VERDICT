# V.E.R.D.I.C.T.

## Verification Engine for Reference, Document, Image & Content Trust

VERDICT is an evidence-backed content verification platform designed to analyze documents, images, URLs and textual claims.

## Core Pipeline

Input
↓
Content Extraction
↓
Claim Detection
↓
Evidence Retrieval
↓
Cross-Verification
↓
Reasoning
↓
Verdict
↓
Evidence & Explanation

## Project Structure

- `frontend/` — User interface
- `backend/` — Backend API and application logic
- `backend/verification/` — Verification and reasoning
- `backend/extraction/` — Content and document extraction
- `backend/evidence/` — Evidence retrieval and analysis
- `tests/` — Automated tests
- `docs/` — Project documentation

VERDICT is currently under active development.
